# Character State

Character state is owned by `glass_character_*` MCP tools and the character rows they update.

Use `glass_check()` for the current compact party hard-state pack, including
inventory and signature moves. Use `glass_character_bulk_get(all_characters=True)` or the
exact character MCP tool named in the injected prompt when full character details
are needed. Resolve pending level-ups when the injected prompt reports them.
Record durable narrative continuity as neutral facts.

Do not edit character markdown files.
